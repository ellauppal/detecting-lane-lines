# Detecting Lane Lines on the Road 
A computer vision pipeline built to identify lane lines on a highway using OpenCV.

## Overview
This project is my solution to [Udacity’s Self-Driving Car Nanodegree Project 1](https://github.com/udacity/CarND-LaneLines-P1).

The pipeline follows a seven-step process: colour thresholding, conversion to grayscale, smoothing, Canny edge detection, region of interest (ROI) selection, line segment detection, and finally, line segment classification and fitting.
